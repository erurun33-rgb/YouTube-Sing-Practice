YouTube Sing Practice（β版）　はじめにお読みください
====================================================

YouTube で歌の練習をするための Chrome 拡張です（試用版）。
  ・キー変更（半音単位、速さはそのまま）
  ・A/B 区間ループ
  ・要確認ポイント（苦手な所に印を付けてすぐ戻る）
  ・動画の上にテキスト・手書きのメモ
  ・自分で入れる歌詞字幕（タップで時刻合わせ、ボーカル記号、行への手書き）


■ 入れ方（最初の1回）
1. この zip を展開し、中の「extension」フォルダを、消さない場所に置きます。
   例：ドキュメント\YouTube-Sing-Practice\extension
   ※ このフォルダを消したり移動したりすると、拡張が動かなくなります。
2. Chrome のアドレス欄に chrome://extensions を入力して開きます。
3. 右上の「デベロッパー モード」を ON にします。利用中も ON のままにしてください。
4. 「パッケージ化されていない拡張機能を読み込む」を押し、1 の「extension」フォルダを選びます。
5. 「YouTube Sing Practice (β)」が一覧に出れば完了です。
   起動時に「デベロッパー モードの拡張機能を無効にする」という案内が出ることがありますが、
   閉じれば（×）そのまま使えます。

■ 使い方
・YouTube の動画ページを開くと、動画の左上に「♪」ボタンが出ます。押すとパネルが開きます。
・練習　：キー（－／＋）、A/B ループ（A と B を Set → Loop ON）
・歌詞　：歌詞を貼り付け →「タップ合わせ」で、歌い出しごとに TAP（または Enter）
          字幕のある動画は「取り込み・書き出し」から YouTube の字幕を取り込めます
・要確認：苦手な所で「＋」やラベルを押して登録。押すとその位置へ戻ります
・注釈　：動画を止めて「＋ テキスト」「＋ 手書き」
・キー変更は、ブラウザの制限で「画面を1回クリックした後」に効きます。

■ 更新のしかた（新しい版を受け取ったとき）
1. 新しい zip を展開し、中の「extension」フォルダの中身で、今のフォルダの中身を上書きします。
   （置き場所は変えないでください）
2. chrome://extensions を開き、「YouTube Sing Practice (β)」の ↻（再読み込み）を押します。
3. 開いている YouTube のタブを再読み込み（F5）します。
   ※ 3 をしないと「拡張が更新されました。タブを再読み込みしてください」と表示されます。
・練習データは、更新しても消えません。

■ データについて（大切）
・練習データ（キー・ループ・要確認・メモ・歌詞）は、このPCの Chrome の中だけに保存されます。
  拡張独自の外部サーバーへは送信しません。字幕はYouTube自身が取得する応答を読み取ります。
・拡張を「削除」するとデータも消えます。PC を移る前や入れ直す前は、
  パネルの「練習」タブ →「バックアップを保存」でファイルに保存し、
  入れ直した後に「読み込む」で戻してください。
・歌詞は、ご自身で入力・取り込みしたものを、ご自身の練習のためだけに使ってください。
  （歌詞の再配布はしないでください）

■ わかっている制限
・パソコン版の Chrome 専用です（スマホ・他のブラウザは対象外）。
・広告の検出時にはキー変更・ループを止める設計ですが、広告ありの実機動作は未検証です。
・キーを大きく変えると、少し音がこもったり響いたりします。
・映像内の歌詞からの時刻合わせは、動画によってはうまく検出できないことがあります。

■ 不具合・要望の伝え方
配布してくれた人に、次の3つを送ってください。
1. 何をしたら、どうなったか（できれば動画の URL と、何分何秒あたりか）
2. スクリーンショット（あれば）
3. ログ：パネル右下の「ログ」を押すと、動作記録がコピーされます。
   そのままメッセージに貼り付けてください。
   （ログには動画のIDと操作の記録が入ります。歌詞の本文やメモの中身は入りません）
