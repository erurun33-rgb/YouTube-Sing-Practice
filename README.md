# YouTube Sing Practice（β版）

YouTubeで歌の練習をするための、パソコン版Chrome用拡張機能です。
キー変更、ABリピート、苦手箇所の記録、テキスト・手書きの注釈、自分で入力する歌詞字幕が使えます。

**[配布ZIPをダウンロード](https://github.com/erurun33-rgb/YouTube-Sing-Practice/releases/download/v0.5.0-beta/ysp-extension-v0.5.0.zip)** · **[最新版の配布ページ](https://github.com/erurun33-rgb/YouTube-Sing-Practice/releases)**

現在の配布版は **0.5.0 beta** です。Chromeウェブストアへの登録は行っていません。インストールにプログラミングやビルド作業は不要です。

## インストール

1. 上の「配布ZIPをダウンロード」を押し、ZIPを展開します。
2. 展開した `YouTube-Sing-Practice` フォルダを、消さない場所（例：ドキュメント）に置きます。
3. Chromeのアドレス欄に `chrome://extensions` と入力します。
4. 右上の「デベロッパー モード」をONにします。利用中もONのままにしてください。
5. 「パッケージ化されていない拡張機能を読み込む」を押し、展開したフォルダ内の **`extension`** フォルダを選びます。`manifest.json` が直接入っているフォルダです。
6. 「YouTube Sing Practice (β)」が表示されたら完了です。開いていたYouTubeのタブは再読み込みしてください。

対応：パソコン版Chrome 116以降。最新版のChromeでの利用をおすすめします。スマホ、YouTube Music、ライブ配信は対象外です。

導入方法の参考：[Chrome公式のローカル拡張の読み込み手順](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)。

## 使い方

YouTubeの動画ページを開き、動画の左上に出る **♪** ボタンを押すとパネルが開きます。

| タブ | 操作 |
| --- | --- |
| 練習 | キーの−／＋で半音単位のキー変更。再生速度は維持します。AとBをSetし、LoopをONにすると区間を繰り返します。 |
| 歌詞 | 歌詞を貼り付け、「タップ合わせ」で歌い出しごとにTAPまたはEnterを押します。行に記号や手書きを付けられます。 |
| 要確認 | 苦手な箇所で＋やラベルを押して登録。一覧からクリックしてその時刻へ戻れます。 |
| 注釈 | 動画を止め、「＋ テキスト」「＋ 手書き」で動画上にメモを付けます。 |

- キー変更は、ブラウザの制限により画面を一度クリックしてから有効になります。
- 再生速度を変えるときはYouTube標準の設定を使ってください。
- 歌詞タブの「取り込み・書き出し」にはYouTube字幕やLRCの取り込みがあります。字幕が取得できない場合は、貼り付けとタップ合わせを使ってください。
- 動画上の手書きは映像の位置と時間に、歌詞の手書きは歌詞の行に付きます。

詳しい説明は [はじめにお読みください.txt](はじめにお読みください.txt) をご覧ください。

## 更新

1. 更新前に「練習」→「バックアップを保存」でデータを保存します。
2. 新しい配布ZIPを展開し、`extension` の中身を、現在読み込んでいる `extension` フォルダへ上書きします。
3. `chrome://extensions` でこの拡張の再読み込み（↻）を押します。
4. YouTubeのタブも再読み込み（F5）します。

**更新のために拡張を削除しないでください。** 削除すると保存データが消えます。配布版の拡張IDは `aebkbcaecjokmihajbmemjhphkgbniam` に固定しています。

以前の開発版を利用している方はIDが異なる場合があります。旧版でバックアップを保存してから配布版へ移し、「練習」→「読み込む」で戻してください。同時に2つの版を動かさないでください。

## データとプライバシー

- 練習データは、このPC・Chromeプロファイルの `chrome.storage.local` に保存します。クラウド同期やログイン機能はありません。
- 拡張独自の外部サーバーへの送信はありません。字幕の取り込みは、YouTubeプレーヤー自身が取得する字幕の応答を読み取ります。
- 歌詞・音源・個人の練習データは配布物に含めていません。
- PCの移行や再インストールの前にはバックアップを保存してください。読み込み時、同じ動画のデータは上書きされます。
- ご自身が入力・取り込みした歌詞は、ご自身の練習用に使ってください。歌詞入りのバックアップを公開リポジトリやIssueに投稿しないでください。

## 制限・不具合の報告

β版のため、動画やYouTubeの仕様によって正常に動かないことがあります。キーを大きく変更すると音質が変わります。広告時の挙動、本物のYouTubeでの字幕応答の取得・映像からの時刻検出には未確認の条件が残っています。

不具合や要望は、配布者への連絡または [Issues](https://github.com/erurun33-rgb/YouTube-Sing-Practice/issues) へお願いします。

1. 何をしたらどうなったか（Chromeの版、拡張の版、動画URL・時刻など）
2. スクリーンショット（個人情報や公開したくない内容は隠してください）
3. パネル右下の「ログ」でコピーした動作記録

ログには動画IDと操作記録が入ります。歌詞本文やメモ本文は含めない設計ですが、公開前に内容をご確認ください。
